## 使用侧与兼容性

自动窗口化复用 `vueuc` 的公开 `VVirtualList`，通过直接依赖声明，未使用 Naive 内部导入，也未将 Naive peer 从 2.35 提高到 2.36。`C_Transfer` 与 `C_Chat` 可用 `virtualScroll=false` 保留完整 DOM。聊天 ID 应唯一稳定，容器应有确定高度。

穿梭框保留 `--tf-height`。聊天变高行不要求业务填写高度；输入法 Enter 确认候选不会发送。公开 `useWaterFallLayout` 四参数调用仍同步，实际组件才显式开启批处理。二维码组件销毁时未完成的导出以 `AbortError` 拒绝；并行导出互不取消。

具体接入与边界见[大列表与异步任务](./guides/runtime-performance.md)及[穿梭框指南](./guides/transfer.md)。

## 代码质量与验证边界

索引、任务和滚动逻辑拆分到各自小模块，模板样式跟随提取的子组件收集；保留公开事件 payload，没有放宽质量或体积预算。合并瀑布流时保留远端的标题高度修复，并将逐条查找和逐元素扫描改为索引，ref 清空、行删除、卸载都会释放观察。

验证采用本机 Bun 1.4.2、Vue 3.5.42、Naive 2.45.3；额外用真实 Naive 2.35.0 包 alias 验证本轮四个相关组件，不将 mock 当兼容证明。

- 合并后完整 `bun run verify`：306 项 Bun 单元、207 项组件挂载，以及 TypeScript/Vue/消费者类型、构建、55 个 ESM/CJS 组件入口、Node16/NodeNext 打包消费者契约均通过。
- Naive 2.35.0：36 项相关挂载测试和四组件类型检查通过。
- `bun install --frozen-lockfile --offline --ignore-scripts` 通过；包与轻量入口体积预算保持原值。消费者依赖复用本机已安装版本，未声称从公开 registry 全新安装尚未发布的版本。
- Chromium 合成场景核对 3000 项穿梭框、5000 项搜索、1000 条聊天及 500 联系人；另验证 199/200 条切换、面板变矮、普通历史前插迟到图片和 IME。明暗主题及窄屏截图检查，未发现运行异常。
- 使用构建后的命名导出及各组件独立 CSS 入口重复 27 项浏览器检查全部通过，确认抽取的消息、联系人和穿梭框行样式包含在按需产物中。
- 瀑布流浏览器核对 100 图、40 个含长标题条目，在 1000/700/420px 容器下无重叠；移除条目立即解除观察，卸载无残留观察目标或 RO 循环错误。

全库 lint 无错误；未修改路径及合入的既有路径仍存在复杂度/解构建议警告，本轮修改的性能模块没有新增警告。以上不替代其他浏览器、真实业务后端或全部第三方引擎的长期压测。

瀑布流此次解决测量和重排，不包含其窗口化协议；媒体运行时配置切换、大文档编辑和特定业务巨量数据仍应按实际 profile 做专项。不能据本轮结果宣称组件库已无优化空间。
