# 生产与销售搜索选择核对

参考源码：2026-11-12 的 `wl-ui-produce`（`2e531d2f`）和 `wl-ui-sale`（`a44017ab`）。本轮实现与演示均在 Naive 组件库内，参考项目和 Robot_Admin 没有接入改动。

## 场景与组件边界

| 参考场景                       | 组件库接入                                                 | 保留在应用侧的内容                 |
| ------------------------------ | ---------------------------------------------------------- | ---------------------------------- |
| 生产钢种、目录关键字搜索       | `C_Select :source`，防抖、取消、远程过滤和分页             | 钢种接口及筛选规则                 |
| 人员编号回显名称               | `source.resolve`，保留原始值类型与未知编码                 | 工位/人员映射                      |
| 仓库 → 货位联动                | Form/Search 的 `source: model => ({ ...source, filters })` | 切换仓库是否清空货位               |
| 自由备注与模板建议             | `C_AutoComplete`，文本输入、失焦保留、本地建议             | 模板加载、启用状态、模板管理       |
| 订单号/项次、企业名称/信用代码 | `C_AutoComplete @select` 完整记录；表单字段助手推导行类型  | 关联字段回填与编辑后清空规则       |
| 快捷候选与高级弹窗             | `C_DataPicker presentation="popover"`，共享选择草稿        | 列定义与请求映射                   |
| 物料、批次、规格多列辨认       | `C_DataPicker columns` + 远程分页                          | 领域字段、单位和精确数值规则       |
| 分类树 + 候选表                | `navigation` 配置；复杂区域用同名 slot                     | 分类目录加载与权限                 |
| 固定工厂、仓库或组织           | `fixedFilters` 最后合并；上下文改变使旧会话失效            | 后端授权与租户隔离                 |
| 禁选、已选去重、数量上限       | 唯一值校验、`rowCheckable`、`maxSelection`                 | 与业务单据比较的具体规则           |
| 跨页选择、确认与取消           | 独立草稿，确认才提交；所有入口共用选择约束                 | 订单提交事务                       |
| 最近使用与收藏                 | 显式 `history`，按 scope/固定条件隔离，选择时重取校验      | 用户标识、业务上下文及长期偏好策略 |
| 搜索/表单/实体字段的视觉一致性 | 共用密度、Naive 主题、状态反馈和键盘交互                   | 页面整体布局和业务信息设计         |

销售订单明细中同一 `orderNo` 可对应多条 `dtlId`。这种场景应绑定唯一明细标识，再从完整行回填订单号和项次；不把重复订单号当作唯一实体值，也不放宽库的重复值检查来掩盖身份冲突。

## 核验入口

- `tests/components/remote-options.component.ts`：远程候选、分页、回显、取消、错误和输入行为。
- `tests/components/data-picker-workflows.component.ts`：选择约束、固定上下文、分类、快捷/完整选择、历史与收藏。
- `tests/components/data-picker-cold-table.component.ts`：真实表格模块慢于加载占位时，初值勾选与公开方法接管仍正常。
- `tests/components/data-picker-batch-results.component.ts`：既有模态/内嵌契约和未解析初值兼容性。
- `tests/consumer/C_SourceFields.vue`：公开 API 的直接使用、来源推导、模型函数和错误回调的编译检查。
- `dev/search-workflows`：离线可操作示例，包含深浅色、密度、失败和上下文切换入口；`bun run dev:search-workflows` 启动。
- `check:consumer-size`：独立组件首屏和 DataPicker 首次打开预算，避免扩展把表格、树或其他大型控件塞入普通字段首屏。

这些能力可以组合覆盖本轮识别的搜索和选择交互。实际业务接口、后端权限、订单领域规则及参考项目替换验收仍需单独接入；本轮结果不等于已经迁移参考项目，也不扩大到报表引擎或 AG Grid 高级能力。
