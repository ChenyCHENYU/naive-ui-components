# 大列表与异步任务

组件保持按需导入和现有事件契约。以下优化默认生效；普通接入无需配置虚拟列表引擎、分页游标或滚动状态。

## 自动减少列表 DOM

| 组件             | 生效条件                           | 保留的语义                                                   |
| ---------------- | ---------------------------------- | ------------------------------------------------------------ |
| `C_Transfer`     | 左右面板分别按筛选后项数，100 项起 | 完整数据筛选、全选、禁用项、移动顺序、v-model                |
| `C_Chat`         | 消息 200 条起；联系人 100 条起     | 图片、文件、系统消息、重发、联系人事件；实际测量变高行       |
| `C_GlobalSearch` | 搜索结果列表                       | 完整匹配结果、上下键跨视口定位、Enter 选择、输入法与历史记录 |

```vue
<C_Transfer v-model="selectedKeys" :data="people" filterable />
<C_Chat :messages="messages" :contacts="contacts" @send="sendMessage" />
<C_GlobalSearch :options="searchOptions" />
```

窗口化复用 `vueuc` 的公开 `VVirtualList`，兼容本包声明的 Naive UI 2.35；不依赖 Naive 内部导入，也不提高 Naive peer 下限。只减少渲染的 DOM，数据仍完整保存在内存中，搜索仍检查完整索引。

穿梭框的三档行高和自定义方式见[穿梭框指南](./transfer.md)。聊天会实测文本、图片和文件行高度，无需调用方预先计算高度。业务 ID 应唯一、稳定；聊天容器应有确定高度，例如外层 `height: 600px`。

若打印、DOM 集成或自定义穿梭框行高需要完整节点，可给 `C_Transfer` 或 `C_Chat` 设置 `:virtual-scroll="false"`。不要把此开关作为加载更多数据的接口；聊天加载历史仍通过 `load-more` 事件及 `loading-history` 状态接入。

## 聊天滚动与输入

打开或切换会话定位最新消息。阅读历史时，新增消息不抢滚动位置；前插历史保留阅读锚点。正在底部时，流式文本、迟到图片与面板高度变化继续跟随。跨越自动窗口化门槛也保持当前阅读状态。

公开 `scrollToBottom()` 可用于主动跳到最新消息。输入法 Enter 确认候选不会提前发送；普通 Enter 保持发送行为。

## 图片、字幕和异步状态

- 瀑布流将同帧图片测量合并为一次布局，参数变化和公开 `relayout()` 仍立即计算。替换图片来源后忽略旧测量，卸载时取消待执行帧。导出的 `useWaterFallLayout` 原有四参数用法保持同步行为。
- 字幕载入时编译时间索引；播放与前后跳转查询使用二分查找，保留重叠字幕按原文件顺序首匹配的语义。
- 代码语言加载只由当前请求更新 loading 和高亮。语言注册后主动更新高亮器引用，同一种语言异步加载完成也会重新着色。复制事件返回点击当时的文本。
- 二维码渲染及每次导出分别保存配置快照。新渲染取消旧 Logo 加载，导出相互独立；卸载取消所有任务并释放 Image 事件。组件销毁期间尚未完成的导出会以 `AbortError` 拒绝，调用方按普通异步错误处理即可。

这些改进不代表列表、瀑布流和编辑器可以无限增加数据。大规模业务仍应按实际场景分段加载、回收历史，并测量内存、交互延迟与目标浏览器表现。
