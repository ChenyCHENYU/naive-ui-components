# 常用组件消费体积 · 0.15.0

同一台机器、同一依赖锁文件下，对本轮收敛前的 `df0f8d4` 与收敛后的构建产物分别创建最小 Vite 应用。每个应用只导入一个组件子路径及对应样式，包含 Vue 与 Naive UI，沿产物的静态导入图累计 JS gzip，动态块不计入首屏。

| 独立消费场景                  |    收敛前 |    收敛后 |     变化 |
| ----------------------------- | --------: | --------: | -------: |
| C_Form，单个 input + base.css | 269.0 KiB | 171.9 KiB |   −36.1% |
| C_Table，单行单列 + base.css  | 336.2 KiB | 220.0 KiB |   −34.6% |
| C_FormSearch，单个 input      | 157.1 KiB | 157.7 KiB | +0.6 KiB |
| C_ActionBar，单个保存按钮     |  85.6 KiB |  86.0 KiB | +0.4 KiB |

日期、时间、滑块、评分、级联、颜色与上传字段通过只使用 Naive 公开导出的独立模块加载；高级表单布局、内置编辑器和表格弹窗表单也延迟加载。基础表单与展示表格的首屏模块图没有这些低频控件，以及编辑器、Excel、截图、打印和 Word 解析依赖。使用相应功能时仍会加载其动态块；异步请求互斥、快照与生命周期保护为查询及动作入口增加了少量代码。

`bun run check:consumer-size` 在每次完整验证和发布前复建这四个场景，预算分别为 200、250、165、95 KiB，同时检查低频控件和重型依赖没有重新进入首屏。CSS 另由 `check:size` 检查；本轮还补齐了表格独立样式中的 ActionBar 依赖，保证使用侧无需全量样式兜底。

测量环境：Node.js 24.19.0、Bun 1.4.2、Vite 8.2.2、Vue 3.5.42、Naive UI 2.45.3。仓库与 CI 的最低环境约定仍见 [开发文档](./engineering.md)。

这些数据是独立构建的传输体积，不能相加估算同一应用的大小，也不代表真实浏览器的加载时延或交互帧率。组件行为通过逻辑测试、Happy DOM 真实挂载、SSR 与打包消费者检查验证；本记录不声称已完成全浏览器或最低 peer 的完整版本矩阵。
