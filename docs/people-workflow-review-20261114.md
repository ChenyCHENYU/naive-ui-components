# 0.36.0 人员选择与审批设计验收

本轮在已发布 0.35.0 的表格适宽修复上集成，以按组织选择人员、配置发起人/审批人/抄送人、绘制条件审批图为范围。实现位于组件库独立分支；Robot_Admin 与 wl 业务项目未迁移。没有新增图引擎或业务依赖。

## 能力归属

| 能力                                          | 归属与使用方式                                  |
| --------------------------------------------- | ----------------------------------------------- |
| 组织树、图标、自定义字段、懒加载与路径搜索    | 沿用 `C_Tree`；选人通过 `organization` 配置复用 |
| 查询、分页、回显、草稿、取消、确认、历史隔离  | `C_DataPicker` 单一选择内核                     |
| 人员默认列、同名辨认、已选名单与顺序调整      | 独立入口 `C_UserPicker`；来源只需注册一次       |
| 节点、连线、分支规则、人员配置与设计快照      | 现有 `C_WorkFlow`；节点配置首次打开时加载       |
| 审批任务执行、权限、通知、并行汇聚、BPMN 转换 | 业务执行端或后续独立阶段                        |

组织点击只筛选候选，不把当前已加载树节点当作完整人员目录。部门是否包含下级由来源策略决定。人员状态通过 `rowCheckable` / `disabledReason` 检查，提供 `resolve` 后默认在确认时重新批量复核。

## 本轮复扫修复

- 返回已访问候选页会重排旧选择：现在保留插入顺序，只有显式上移/下移才调整。
- 异步确认期间改变必选、只读、数量或来源范围：提交前复核当前规则与会话，取消和迟到结果不回写。
- 内嵌选择器替换固定筛选后关闭且无法再打开：按实际筛选变化重开新会话，等值对象不丢草稿。
- 同名人员在已选区难以辨认：显示业务编码、部门和不可选原因。
- 画布回填连线被交互重复边判断过滤：已有图交给显式校验，新增连接继续检查重复、自连和回环。
- 键盘删除绕过发起节点与分支保护：统一使用受保护删除逻辑；输入、只读状态忽略画布删除键。
- 保存人员顺序/标题后快照正确但画布仍旧：通过节点数组引用更新同步实际渲染，回归直接检查画布文字。
- `fitView` 数字留白被 SDK 解释为比例：统一显式像素单位。
- 独立入口遗漏依赖样式：人员入口包含 DataPicker 样式闭包；流程包含节点配置和 SDK 基础定位样式。SDK 选择器、动画名称限制在设计器内。
- 连线整组描边污染标签、无头像人员留空、只读预览保存按钮仍可点：分别收敛到路径描边、本地头像和禁用操作。

## 浏览器验收

独立演示使用打包后的正式子路径，人员来源为可取消的离线适配器：

```sh
bun run build
bun run dev:search-workflows
```

打开 `http://127.0.0.1:4188/people-workflow.html`：

1. 打开协作成员选择器，展开组织，切换部门并输入姓名/工号；翻页勾选、调整顺序后确认。取消重开应恢复原业务值。
2. 点击“下次查询失败”，重开选择器，检查错误与重试；重试后保留已选名单。切换业务范围时演示会同步清空该主体的业务值。
3. 点击财务复核节点，调整顺序审批人员后确定；画布和再次打开的名单应立即一致。
4. 点击条件节点检查数值、默认分支、下游和优先级。拖动输出端口建立连接；回环连接在演示的无环配置下不可创建。
5. 验证与保存设计，检查节点/连线数量；切到只读后预览仍可用，保存与结构操作禁用。

实际通过了上述选人/重试、组织搜索、取消、排序、拖线、禁止回环、设计保存、条件配置与只读预览交互。明暗主题均检查；390px 视口文档宽度为 390px，三栏纵向排列且底部按钮可滚动到达。验收标签页未记录控制台错误。

## 后续边界

当前无需再加一套选人状态机、组织勾选映射或图编辑器。接入真实业务时优先验证来源适配器的权限范围、取消信号、分页与按编码解析；最终提交仍由服务端复核。

演示人员为小规模样本；首屏体积、分页与组件回归不能代替生产规模组织/流程的延迟和内存数据。大图布局、并行汇聚和审批执行指标应在实际场景明确后单独设计与测量，不把设计预览当作执行成功。
