# 0.24.3 稳定性复核

日期：2026-10-31。基线：0.24.2。本轮保留现有组件、主题、精简配置和公开接口，通过复现处理真实边界问题，不建立新的状态框架、全局缓存或通用虚拟化层。

## 范围与发现

公共值工具、字典与工作流入口，以及表单、搜索、表格、图、地图、上传、媒体等高风险组件是本轮重点。其他资源组件结合源码检查和现有生命周期回归复核；这不等同于所有第三方引擎和业务环境都完成压力测试。

| -------------- | ------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------- |

## 性能与复杂度

- 字典仅在选项快照更新时创建索引，表格单元格按索引解析；不添加共享网络缓存，身份与租户隔离仍由应用 Provider 持有。
- 列拖拽只有开启时追踪列结构，使用组件内惰性列 Map；不按数据行扫描，不因内容测宽变化重建实例。
- 数据比较保留短路、循环处理和 O(N) 稠密数组遍历，不创建额外数组键列表。既有大表单比较缓存和集合线性查询回归继续通过。
- 400 字段普通表单与弹窗仍验证仅被编辑控件更新。完整模型快照仍有与模型大小相关的成本；大量重复明细使用虚拟表格，异构大表单使用已有 Tabs/Steps 分区。
- 单个小窗锚点只在进入小窗时记录一次原高度，没有持续测量任务；第三方实例继续使用浅引用，未增加运行时依赖。
- 显式 any 从 108 降至 106，并把总预算从 117 收紧到 106；没有把第三方边界强行改为错误类型，也没有用忽略注释隐藏类型错误。

对外的 deprecated 类型或兼容入口仍有公开消费契约，不把“已标记废弃”当成“无人使用”。补丁仅删除已确认的死状态、重复渲染逻辑和不可达分支，避免破坏已有使用侧。

本轮新增路径没有新增 lint 警告。当前仍有 18 条既有提示，主要是公式/Cron 解析器分支、表格渲染分派和旧参数数量；没有为降低统计数字而拆散解析状态机或改变公开参数。本次不是“零技术债”的声明，后续按可验证收益渐进收敛。

- `bun run verify`：485 项逻辑测试、495 项组件测试，TypeScript/Vue/消费者类型、lint、旧 API 扫描、导出、vendor、构建、ESM/CJS、Node16/NodeNext 和可选 peer 契约全部通过。
- 原有发布体积和消费者 gzip 预算全部通过，没有放宽限额；完整可用包约 5.13 MiB（含单列预算的 SheetJS）。
