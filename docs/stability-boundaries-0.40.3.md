# 0.40.3 交互与生命周期边界闭环

日期：2026-11-15。基线：0.40.2。修复以可复现问题为范围，公开属性、模型、配置和类型入口保持兼容。C_Table 仅修改公开查询 hook 的取消与销毁处理，渲染、列配置、布局与高级表格能力不变；MachTable 未改动。

## 修复与回归

`saveEvent/deleteEvent` 提交当前打开的日历 UI 会话；程序化数据写入继续使用既有 `expose.addEvent/updateEvent/deleteEvent`。不会把父列表的任意变化都当作取消理由，也不建立全列表快照缓存。

翻译函数通过 JavaScript `in` 建立缺失消息键的存在性依赖，并继续使用自有属性检查排除继承字段。无 Vue 运行依赖进入 core。上传内置词表仅随上传入口加载，应用 messages/t 仍优先，未增加公开语言配置或第二套 Provider。

## 质量与文档

- 类型计数补齐模板绑定、插值、插槽参数及 SFC generic 属性；忽略注释、字符串和静态 HTML，解析失败直接阻断。新增 7 项统计回归。
- 移除 Upload 的模板宽泛断言。当前合计 102 个显式 any（含两处既有模板断言），14 个 console；总预算及重点组件预算按当前实值收紧，没有为 SDK 类型归零而改写引擎契约。
- 修正 `/config` 的中英文文档：它还导出色板和主题工厂，原生 CJS 会加载 Naive UI；组件注册、路由与消息／弹窗反馈适配器仍不由该入口加载。
- 甘特生命周期测试显式等待真实动态模块就绪，再执行原有实例断言；避免把 SDK 冷加载混入假时钟轮询期限，未改生产甘特或增加测试超时。
